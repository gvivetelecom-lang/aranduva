# Alcance de la demostración V29

## Qué representa

El prototipo permite **visualizar y explorar** la propuesta ARANDUVA: interfaz, flujos de navegación, roles ficticios, experiencias de consulta, calendario, eventos, salas, foros y ayuda académica contextualizada.

## Qué no representa

- Universidades integradas o con acuerdos firmados.
- Autenticación, control de acceso o privacidad aptos para uso real.
- Videoconferencias o transmisiones reales.
- Chat, moderación, IA, mensajería o notificaciones conectadas a servicios externos.
- Un servicio backend persistente o una red pública de producción.
- Validación pedagógica, legal, técnica o presupuestaria concluida.

## Próximas etapas sugeridas

1. Validar necesidades con estudiantes, docentes y coordinación académica.
2. Revisar derechos de fotografías, textos y marcas.
3. Rediseñar un repositorio modular con tests y herramientas de desarrollo.
4. Realizar pruebas de accesibilidad, dispositivos móviles y navegadores.
5. Definir seguridad, infraestructura, privacidad y autorización institucional.
6. Implementar integraciones reales en un piloto acotado con consentimiento y métricas.

## Presupuesto conceptual

Los tres rangos históricos discutidos —US$700–800, US$1.000–1.500 y US$2.000–4.000 mensuales— son **hipótesis de planificación**, no cotizaciones de servicios ni costos garantizados.
